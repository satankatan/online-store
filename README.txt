«Urban Muse» — веб-приложение интернет-магазина одежды

 1. Назначение и концепция
Проект представляет собой одностраничное веб-приложение (SPA) интернет-магазина стильной одежды. Пользователь может:
- просматривать каталог товаров (верхняя одежда, верх, низ, обувь);
- искать товары по названию;
- фильтровать по категориям;
- открывать карточку товара с выбором размера и цвета;
- добавлять товары в корзину;
- изменять состав корзины, видеть итоговую сумму;
- проходить регистрацию и вход (имитация аутентификации);
- оформлять заказ с заполнением адреса и выбором способа оплаты (карта, СБП, наложенный платёж);
- получать подтверждение заказа с уникальным номером;
- просматривать информацию о магазине, доставке, возврате, FAQ.

Интерфейс полностью адаптивен (мобильные устройства, планшеты, десктоп).


 2. Технологический стек
- HTML5 – семантическая разметка, кастомные теги (`<details>`, `<summary>`).
- CSS3 – кастомные свойства (CSS‑переменные), Flexbox, Grid, градиенты, анимации, адаптивные медиа‑запросы.
- JavaScript (ES6+) – вся логика: рендеринг страниц, управление состоянием (корзина, пользователь), фильтрация, маршрутизация по хэшу (`catalog`, `cart`, `checkout`), взаимодействие с `localStorage` для хранения данных.
- LocalStorage – персистентное хранение корзины, данных зарегистрированного пользователя, заказов.
- Font Awesome / иконочные символы – звёздочки рейтинга, простые графические элементы.


 3. Архитектура и ключевые модули
 Маршрутизация (SPA)
Все «страницы» – это секции `<section class="page">` с уникальными `id`.  
При изменении `location.hash` срабатывает функция `route()`, которая:
- скрывает все секции;
- показывает секцию с соответствующим `id`;
- вызывает специализированный рендер (каталог, корзина, чек-аут).

 Состояние приложения
Глобальный объект `state`:

{
  cart: [],    // { id, qty, size, color }
  user: null   // { name, email }
}

Все изменения корзины/пользователя сохраняются в `localStorage` и синхронизируются с отображением счётчика товаров, суммы корзины и т.д.

 Генерация товаров
Статический массив `products` (18 позиций) содержит:
- `id`, `name`, `category`, `price`, `rating`, `badge` (скидка или метка «Хит»/«Новинка»);
- описание, размеры, цвета, путь к изображению.

Для каждого товара задаётся категория, размерная сетка (одежда – XS…XL, обувь – 36…41).

 Динамический рендеринг карточек
- `renderCatalog()` – фильтрует товары по `currentFilter` и `searchTerm`, генерирует HTML для `.products-grid`.
- `renderProduct()` – показывает детальную страницу товара с выбором размера и цвета, таблицей размеров, рекомендациями по уходу.

 Корзина
Функции `addToCart`, `removeFromCart`, `updateCartCount`, `renderCart`.  
При добавлении проверяется наличие такого же товара с одинаковым размером/цветом – если есть, увеличивается количество, иначе создаётся новая запись.

 Аутентификация (упрощённая)
Формы регистрации и входа. Пароль хранится в открытом виде в `localStorage` (демонстрационный режим). После успешного входа пользователь сохраняется в `state.user`, появляется возможность просмотра профиля и кнопка выхода.

 Оформление заказа
- Форма собирает данные доставки (имя, телефон, город, адрес).
- Выбор способа оплаты: карта, СБП, наложенный платёж (при выборе карты динамически появляются поля для номера, срока, CVC).
- Валидация: проверка заполнения обязательных полей, формата номера карты, срока (MM/YY), CVC.
- После успешного оформления создаётся объект заказа с уникальным ID (`MU-XXXXXX`), сохраняется в `localStorage` (`shop.orders`, `shop.lastOrder`), корзина очищается, пользователь перенаправляется на страницу `orderSuccess`.



 4. Дизайн и пользовательский опыт (UI/UX)
 Визуальные особенности
- Цветовая схема: тёмно-фиолетовый акцент (`8f3dff`), розовый акцент (`ff6b9b`), светлый фон (`f7f3ef`).
- Скругления: везде используются крупные `border-radius` (от 12px до 24px) – современный, «мягкий» стиль.
- Тени: `box-shadow` создаёт эффект приподнятости карточек и кнопок.
- Градиенты: фон героя, кнопок, промо-баннера, карточек – придают глубину.
- Блюр хедера: `backdrop-filter: blur(8px)` делает шапку полупрозрачной.

 Интерактивность
- Фильтры и поиск работают без перезагрузки страницы.
- Карточки каталога имеют две кнопки: «Подробнее» (переход на страницу товара) и «В корзину» (добавление с размерами/цветом по умолчанию).
- На странице товара – переключатели размера и цвета (активный элемент подсвечивается градиентом).
- Корзина отображает миниатюры, вариант (размер/цвет), позволяет удалять позиции.
- Форма заказа динамически скрывает/показывает поля карты в зависимости от выбранного способа оплаты.

 Генерация SVG-картинок-заглушек (fallback)
Функция `productImage(kind, accent, label)` создаёт векторные изображения товаров на случай отсутствия реальных фото. В текущей версии используются реальные изображения из папки `./assets/` (например, `coat.jpg`), но код SVG остался как резервный механизм.



 5. Нестандартные решения и интересные детали
1. Маршрутизация по хэшу без внешних библиотек – компактный и рабочий способ SPA.
2. Динамическая таблица размеров – в зависимости от категории товара (верх, низ, обувь) отображается разная сетка.
3. Валидация карты на фронтенде – имитация безопасной оплаты (поля карты обязательны, проверяется длина номера, корректность срока).
4. История заказов – хотя в интерфейсе нет отдельного раздела «Мои заказы», все оформленные заказы накапливаются в `localStorage` под ключом `shop.orders` (можно легко расширить).
5. Сохранение корзины и пользователя – данные не теряются после перезагрузки страницы.
6. Семантический HTML – используются `<section>`, `<article>`, `<details>`, `<summary>`, что полезно для доступности и SEO.
7. Адаптивная вёрстка – при ширине меньше 760px колонки схлопываются, шрифты и отступы остаются читаемыми.



 6. Заключение
«Urban Muse» – это полноценный фронтенд-прототип интернет-магазина с проработанной логикой корзины, заказов, аутентификации и адаптивным дизайном. Проект демонстрирует навыки создания SPA на нативном JavaScript, работы с DOM, событиями, `localStorage`, а также современные подходы к вёрстке (CSS Grid, Flex, кастомные свойства, градиенты). Его можно использовать как основу для дальнейшей разработки с подключением реального API и платёжных систем.
